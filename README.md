## Поток данных

### 1️ Создание задачи

```
Пользователь заполняет форму
         ↓
React компонент (TaskManager.js)
         ↓
Отправляет POST /api/tasks с JSON:
{
  "title": "Проект 1",
  "description": "...",
  "progress": 50,
  "hours_per_week": 22,
  "load_per_month": 22,
  "weekly_info": "Сделал то то",        
  "planning": "Буду то то",              
  "help_needed": "нет"                   
}
         ↓
Backend: CreateTask() handler
         ↓
Валидация данных
         ↓
INSERT в БД (tasks таблица)
         ↓
Сохраняется с NEW ПОЛЯМИ
         ↓
Ответ со статусом 201
         ↓
Frontend получает ответ
         ↓
Добавляет задачу в список
         ↓
Показывает пользователю
```

---

### 2 Экспорт в Excel

```
Пользователь нажимает "Скачать отчёт"
         ↓
React вызывает GET /api/reports/all-tasks
         ↓
Backend: ExportAllTasks() handler
         ↓
SELECT из БД всех задач:
SELECT 
  ROW_NUMBER() as row_num,
  users.username,
  tasks.title,
  tasks.weekly_info,        
  tasks.planning,           
  tasks.help_needed,        
  tasks.hours_per_week,
  tasks.load_per_month
FROM tasks JOIN users
         ↓
Формирует Excel через excelize:
┌────┬──────────┬──────────┬────────────────┬───┐
│ №  │   ФИО    │ Проекты  │ За неделю      │...│
├────┼──────────┼──────────┼────────────────┼───┤
│ 1  │ *****    │ ******** │ ************   │...│
└────┴──────────┴──────────┴────────────────┴───┘
         ↓
Отправляет файл браузеру
         ↓
Браузер скачивает файл
         ↓
statistics_by_projects.xlsx на компьютере
```

---

### 3️ Просмотр и редактирование

```
Пользователь видит список задач
         ↓
Нажимает "Изменить"
         ↓
TaskManager переходит в режим редактирования
         ↓
Показывает текущие значения в полях
         ↓
Пользователь меняет данные
         ↓
Нажимает "Сохранить"
         ↓
React отправляет PUT /api/tasks/:id
         ↓
Backend: UpdateTask() обновляет ВСЕ поля:
UPDATE tasks SET
  title = ?,
  description = ?,
  progress = ?,
  hours_per_week = ?,
  load_per_month = ?,
  weekly_info = ?,        
  planning = ?,           
  help_needed = ?,        
  updated_at = CURRENT_TIMESTAMP
WHERE id = ?
         ↓
БД обновляется
         ↓
Backend возвращает успех
         ↓
Frontend обновляет интерфейс
         ↓
Пользователь видит обновлённые данные
```

## Модель данных (Entity-Relationship)

```
┌──────────────────┐
│     USERS        │
├──────────────────┤
│ id (PK)          │
│ username         │◄───────────┐
│ password_hash    │            │
│ role             │            │
│ department       │            │
│ created_at       │            │
└──────────────────┘            │
                                │
                         (ONE-TO-MANY)
                                │
                    ┌───────────┴────────────┐
                    │                        │
┌─────────────────────────────────────────────┐
│            TASKS                            │
├─────────────────────────────────────────────┤
│ id                    [INTEGER]             │
│ title                 [VARCHAR(255)]        │
│ description           [TEXT]                │
│ progress              [INTEGER 0-100]       │
│ hours_per_week        [DECIMAL]             │
│ load_per_month        [INTEGER 0-100]       │
│ weekly_info            [TEXT] ← НОВОЕ       │
│ planning               [TEXT] ← НОВОЕ       │
│ help_needed            [TEXT] ← НОВОЕ       │
│ user_id (FK)   ─────→ USERS.id              │
│ created_at             [DATETIME]           │
│ updated_at             [DATETIME]           │
└─────────────────────────────────────────────┘
```

## Роли пользователей и доступ

```
┌─────────────────────────────────────────────────────────────┐
│                    ROLE-BASED ACCESS                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   USER (Обычный пользователь)                               │
│   └─ Видит: только свои задачи                              │
│   └─ Может: создавать, редактировать, удалять свои          │
│   └─ Экспорт: только свои задачи (my-tasks)                 │
│                                                             │
│   MANAGER (Менеджер)                                        │
│   └─ Видит: задачи своего отдела                            │
│   └─ Может: редактировать задачи отдела                     │
│   └─ Экспорт: статистика отдела (department-stats)          │
│                                                             │
│   ADMIN (Администратор)                                     │
│   └─ Видит: ВСЕ задачи всех пользователей                   │
│   └─ Может: редактировать ВСЕ задачи                        │
│   └─ Экспорт: статистика по всем проектам (all_projects)    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
